Two-Ring Isolation & Omnichannel Architecture

AgendaVoice AI enforces data boundaries at two independent layers: physical PostgreSQL Row-Level Security between companies (Ring 1), and branch-scoped access control with Blind Upsert resolution between branches of the same company (Ring 2).

01 Strict Branch Isolation

Operators assigned to Branch A (Las Condes) cannot list appointments, check staff schedules, or browse customers belonging exclusively to Branch B (Providencia). All unauthorized branch IDs return 404.

02 Industry-Standard Blind Upsert

When a Branch A customer calls Branch B to book, the operator enters their phone number (+569...). POST /appointments links the customer record cleanly without exposing Branch A's history or requiring an admin.

03 Zero Double-Booking (GiST)

PostgreSQL enforces EXCLUDE USING gist over tstzrange(starts_at, ends_at, '[)') combined with ordered pg_advisory_xact_lock locks so simultaneous voice, web, and WhatsApp requests never collide.
